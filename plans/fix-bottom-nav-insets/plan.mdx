# Fix: Content Cut Off Behind Bottom Navigation

## Problem

Content on Tools, Discover, and Profile/My Board screens is cut off or hidden behind the bottom navigation bar. The last tool card on Tools isn't fully tappable, section titles and "See all" buttons on Discover are clipped, and empty states/lists on Profile lack safe bottom spacing.

## Root Cause

`HomeDecorApp.kt:178` sets `contentWindowInsets = WindowInsets(0)` on the Scaffold, disabling all automatic inset handling. The Scaffold's `padding` only includes the bottomBar (NavigationBar) height, not the system navigation bar insets underneath it. Screens must manually account for the system nav bar, but none do — they only handle `statusBars` at the top.

## Approach

Two complementary fixes:

1. **Scaffold fix** (`HomeDecorApp.kt`): Remove `contentWindowInsets = WindowInsets(0)` so the Scaffold properly accounts for system insets via `innerPadding`. This ensures the content Box always sits above both the app's NavigationBar and the system navigation bar.

2. **Screen cleanup** (3 files): Remove the now-redundant `windowInsetsPadding(WindowInsets.statusBars)` from each screen's header/root, since the Scaffold's `padding` already includes status bar height. For MyBoardScreen, also remove the compensating `Spacer(Modifier.height(48.dp))` and add bottom padding to scrollable content.

This lets Material 3 Scaffold automatically apply `WindowInsets.systemBars` to the content area. The `padding` parameter will now include status bar + navigation bar insets plus the bottomBar height.

## What This Does NOT Change

- **`WizardSteps.kt` / `StepScaffold`**: The Create tab hides the bottom nav bar (`if (selectedTab != MainTab.Create)`), so `StepScaffold`'s own `windowInsetsPadding(WindowInsets.navigationBars)` on its bottom bar (line 427) continues to work correctly. No changes needed.
- **Modal sheets** (`PaywallSheet`, `DiamondStoreSheet`, `AuthSheet`, `SettingsSheet`, `DesignViewerSheet`): These handle their own insets independently. Not affected by this change.
- **`ProfileScreen.kt`**: Unused file (not in navigation). Not changed.
