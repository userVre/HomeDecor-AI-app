# Reference Style Transfer Flow Redesign

## Context

The Reference Style Transfer tool in HomeDecor AI uses a multi-step wizard flow: **Photo → Style → Refine → Processing → Result**. The user wants to modernize the UI across all steps with cleaner visuals, better validation UX, and a premium processing screen. All changes target Kotlin/Jetpack Compose with Material 3 Expressive design.

**Primary file:** `app/src/main/java/com/ismail/homedecorai/ui/tools/WizardSteps.kt` (3426 lines)
**Supporting files:** `SharedComponents.kt`, `WizardStepValidation.kt`, `strings.xml`

## Step 1: Upload Screen — Remove Step Indicators & Redesign Upload Card

**File:** `WizardSteps.kt`

The `DesignStepHeader` (line 294) shows `Step X/Y` text + a progress bar. For the reference tool's Photo stage, hide these.

**Change:** Add a `showStepIndicator: Boolean = true` parameter to `DesignStepHeader`. In `CreateScreen` (line 226), pass `showStepIndicator = false` when `state.selectedTool.id == "reference" && state.wizardStage == WizardStage.Photo`.

In `DesignStepHeader`, wrap the step counter text + progress bar Row (lines 357-383) in `if (showStepIndicator)`.

### 1b. Redesign ReferenceDualImagePicker upload card

- Clean dashed border (already present, keep `BorderStroke(1.5.dp, StudioLine.copy(alpha = 0.6f))`)
- Subtle upload icon in the empty state (replace `Icons.Rounded.PhotoLibrary` with `Icons.Rounded.CloudUpload` for a more modern feel)
- Remove the redundant title inside the container — keep only helper text "Upload a style reference to continue." (already uses `upload_style_reference_helper` string)

**Specific changes to `ReferenceDualImagePicker` (line 564-668):**

- Replace `Icons.Rounded.PhotoLibrary` with `Icons.Rounded.CloudUpload` in the empty state (line 633)

### 1c. Remove bottom decorative icons after photo selection

The `ReferenceImagesStep` (line 483) shows an "Try with example" `OutlinedButton` at the bottom (lines 549-559) when `!hasRoom || !hasReference`. The user wants this removed or simplified. **Change:** Remove the `OutlinedButton` block (lines 549-559) from `ReferenceImagesStep`. Users can still use the "Example" button inside each picker card.
